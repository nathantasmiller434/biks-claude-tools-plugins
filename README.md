## Overview

BIKS Claude Tools is designed to make Claude Code plugin discovery and installation easier to manage. It presents available plugins in a dedicated marketplace experience, allowing users to connect that marketplace to Claude Code or select plugins individually without maintaining a manual list.

The project is intended for users who want a more organized way to explore Claude Code extensions. From initial browsing through plugin selection and installation, the marketplace keeps these activities together in one focused interface.

## What It Provides

- Displays available plugins in a marketplace-oriented listing
- Enables marketplace integration with Claude Code
- Allows plugins to be installed individually
- Supports workflows centered on Claude Code plugins
- Makes plugin discovery more direct

- Covers browsing, choosing, and installing plugins

1. Start BIKS Claude Tools.
2. Review the available plugin entries.
